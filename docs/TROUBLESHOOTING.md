# PlayCue トラブルシューティング

よくある問題と対処法をまとめています。  
解決しない場合は、エラーメッセージをメモしてから GitHub の Issue を作成してください。

---

## Python が見つからない

**症状:** `python` コマンドが認識されない。

**確認手順:**

1. Python 3.11 以上がインストールされているか確認します。
   ```powershell
   python --version
   ```
2. `Python 3.11.x` などと表示されない場合は [python.org](https://www.python.org/downloads/) からインストールしてください。
3. インストール時に「Add Python to PATH」にチェックを入れてください。チェックを入れ忘れた場合は再インストールが必要です。
4. インストール後、PowerShell を再起動してから再実行してください。

---

## `pip install` に失敗する

**症状:** `python -m pip install -r requirements.txt` がエラーになる。

**確認手順:**

1. Python のバージョンを確認します（3.11 以上）。
   ```powershell
   python --version
   ```
2. ネットワーク接続を確認します。プロキシ環境では追加設定が必要な場合があります。
3. PowerShell を管理者として起動してから再実行してみてください。
4. pip 自体を更新してから再試行します。
   ```powershell
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt
   ```

## `python PlayCue.py` で起動しない

**症状:** 実行してもウィジェットが開かない、またはエラーが表示される。

**確認手順:**

1. 依存関係をインストール済みか確認します。
   ```powershell
   python -m pip install -r requirements.txt
   ```
2. 構文エラーがないか確認します。
   ```powershell
   python -m py_compile PlayCue.py
   ```
3. 表示されるエラーメッセージを確認します。  
   `ModuleNotFoundError` であれば依存関係が不足しています。  
   `PermissionError` であれば管理者権限で実行してみてください。
4. PowerShell を管理者として起動して再実行してください。

---

## ゲームの exe が見つからない

**症状:** ゲームを起動しようとしても何も起きない。

**確認手順:**

1. 設定画面を開き、対象ゲームの `ランチャーexe またはゲームexeのパス` を確認します。
2. `参照` ボタンで正しい exe ファイルを選び直してください。
3. ゲーム本体が別の場所に移動・再インストールされていないか確認します。

---

## ゲームは起動するがプレイ時間が記録されない

**症状:** ゲームを起動できるが、終了後に履歴が増えない。

**確認手順:**

1. 設定の `プロセス名` が正しいか確認します。
2. タスクマネージャーを開き、ゲーム実行中の「プロセス名」列に表示される `.exe` 名と一致しているか確認します。
3. 大文字・小文字・スペルを正確に入力してください（例: `Game.exe`）。
4. ランチャーを使うゲームの場合は、次の項目も確認してください。

---

## ランチャー経由のゲームでプレイ開始が記録されない

**症状:** ランチャーからゲームを起動したが、プレイ時間の計測が始まらない。

**確認手順:**

1. 設定の `active_process_name` が正しく設定されているか確認します。
2. `active_process_name` には、ランチャーが終了した後に実際に起動するゲーム本体のプロセス名を入力してください。
3. タスクマネージャーでゲーム起動中に表示されるプロセス名を確認し、それを `active_process_name` に設定してください。
4. `active_process_name` が未設定の場合、`process_name` がそのまま使われます。

---

## OBS が起動しない

**症状:** OBS 自動起動が有効なのに OBS が開かない。

**確認手順:**

1. OBS Studio がインストールされているか確認します。
2. 設定の `OBS設定` → OBS の exe パスが正しいか確認します。  
   通常は `C:/Program Files/obs-studio/bin/64bit/obs64.exe` などです。
3. 管理者権限が必要な場合は、OBS 自体を管理者として起動してみてください。
4. OBS を手動で起動できるか確認し、起動できない場合は OBS の再インストールを試みてください。

---

## OBS WebSocket に接続できない

**症状:** OBS は起動しているのに「OBS に接続できません」と表示される。

**確認手順:**

1. OBS の `ツール` → `WebSocket サーバー設定` を開き、WebSocket サーバーが有効になっているか確認します。
2. ポート番号が PlayCue の設定と一致しているか確認します（デフォルト: 4455）。
3. パスワードが正しく入力されているか確認します。
4. OBS が完全に起動した後に PlayCue を起動してみてください。
5. Windows ファイアウォールが OBS の WebSocket 通信をブロックしていないか確認します。

---

## 録画が開始されない

**症状:** ゲームを起動しても OBS の録画が始まらない。

**確認手順:**

1. 設定の `obs.auto_start_recording_on_game_launch` が有効になっているか確認します。
2. OBS の録画設定（出力先フォルダ）が正しく設定されているか確認します。
3. 出力先ドライブの空き容量が十分にあるか確認します。
4. OBS に WebSocket 接続できているか確認します（前項参照）。

---

## 録画停止に失敗する

**症状:** ゲーム終了後も OBS の録画が止まらない、またはエラーが表示される。

**確認手順:**

1. OBS が録画中の状態かを確認します（OBS の録画ボタンが赤くなっているか）。
2. OBS 側で録画設定に問題がないか確認します。
3. OBS の WebSocket 接続が切れていないか確認します。
4. OBS を再起動して再試行してください。

---

## ログが保存されない

**症状:** ゲーム終了後に `logs/play_history.csv` が更新されない。

**確認手順:**

1. `logs/` フォルダが存在するか確認します。存在しない場合は手動で作成してください。
2. `logs/play_history.csv` を Excel などのアプリで開いたまま PlayCue を使用すると、書き込みに失敗することがあります。ファイルを閉じてから再試行してください。
3. `logs/` フォルダへの書き込み権限を確認します。
4. 管理者権限で PlayCue を起動してみてください。

---

## 設定ファイルが壊れている

**症状:** 起動時に「設定ファイルが読み込めません」などのエラーが表示される。

**確認手順:**

1. 問題のある `configs/` 以下の JSON ファイルを別の場所へ移動（バックアップ）します。
2. `configs/example.json` を参照して、新しい設定ファイルを作成します。  
   または、ウィジェットの `設定` → `ゲーム追加` から再作成してください。
3. JSON の構文ミス（カンマ、括弧の過不足）がある場合は、テキストエディタで修正してください。

---

## タスクトレイに入らない

**症状:** ウィジェットを最小化してもタスクトレイに表示されない。

**確認手順:**

1. 依存ライブラリ `pystray` と `Pillow` がインストールされているか確認します。
   ```powershell
   python -m pip install pystray Pillow
   ```
2. タスクバーの通知領域（隠れているアイコン）にある場合があります。`^` ボタンで確認してください。
3. 再インストールして再起動してみてください。
   ```powershell
   python -m pip install --force-reinstall pystray Pillow
   ```

---

## 文字が見えにくい

**症状:** ウィジェットのテキストや背景が見づらい。

**確認手順:**

1. 使用しているテーマ（ライト / ダーク）がシステムの表示設定と合っているか確認します。
2. ウィジェットのウィンドウサイズを変更してみてください。
3. 選択状態によって色が変わることがあります。別のゲームを選択して確認してください。

---

## 管理者権限の確認が出る

**症状:** 起動時に「管理者権限を要求しますか？」と表示される。

**説明:**

PlayCue では、ゲームの起動や OBS の連携に管理者権限が必要になる場合があります。  
管理者権限のダイアログが表示されたら「はい」を選択してください。  
頻繁に表示される場合は、PlayCue 自体をショートカットから「管理者として実行」するよう設定できます。

---

## それでも解決しない場合

1. エラーメッセージ全文をメモします。
2. 使用している OS バージョン、Python バージョン、OBS バージョンを確認します。
3. GitHub の Issue ページに内容を投稿してください。
